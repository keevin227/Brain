# Luna · opening presentation

Persian (RTL) opening deck: from "feature" to "platform", then the Profit · Control · Insight triangle.
Live: https://keevin227.github.io/Brain/

- Edit `src/deck.html`, then run `python3 build.py` to regenerate the self-contained `index.html` (the Vazirmatn font is inlined from `src/fonts.css`).
- Controls: ← / Space next, → back, `N` speaker notes (full speech text), `F` fullscreen, swipe on mobile, `#5` jumps to slide 5.
- Final button: open with `?product=https://your-app-url` to hand over to the live product.
- Visual style follows the BuildEasy template; the Luna orb painter, graph palette and value triangle come from the ValueGram landing page.
