# Luna · opening presentation

English (default, index.html) and Persian (fa.html) opening deck: from "feature" to "platform", then the Profit · Control · Insight triangle.
Live: https://keevin227.github.io/Brain/

- Edit `src/deck.html`, then run `python3 build.py` to regenerate `index.html` (English, via `src/en.py`) and `fa.html` (Persian) (the Vazirmatn font is inlined from `src/fonts.css`).
- Controls: Space or the arrow pointing forward = next (→ in English, ← in Persian), `N` speaker notes (full speech text), `F` fullscreen, swipe on mobile, `#5` jumps to slide 5.
- Final button: open with `?product=https://your-app-url` to hand over to the live product.
- Visual style follows the BuildEasy template; the Luna orb painter, graph palette and value triangle come from the ValueGram landing page.
